Verzerrt ein Bild und tastet die Farbkanäle versetzt ab, wie Licht im Prisma. Dieses Tool spricht Patchbay: Im Deck wird es zum Node, gleiche Einstellungen ergeben immer dasselbe Bild.

Wartet auf ein Bild aus dem vorigen Node.
Im Patchbay-Deck einbinden: „Neues Tool“ → „Tool per URL einbinden“ und diese Adresse eintragen.
Effekt ursprünglich erstellt mit Brik, für Patchbay portiert · Zum Patchbay-Deck
